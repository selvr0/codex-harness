# 이미지 강조 (highlight)

입력은 이미지 파일 하나임. 원본은 고치지 않고 새 파일로 만듦.

이미지 처리 라이브러리 없이 동작함. 브라우저(headless)에 이미지를 띄우고 박스를 얹은 뒤 다시 찍는 방식임.

박스 모양: 빨간 테두리 4px, 영역보다 6px 넓게, 박스 바깥은 60% 어둡게.

## 설치 (처음 한 번)

```bash
cd <이 스킬 폴더>
bash scripts/setup.sh      # screenshot 스킬을 이미 설치했으면 브라우저는 다시 받지 않음
bash test/selftest.sh      # 시험 이미지에 박스·흐림을 그려 test/out/ 에 남김
```

- selftest 가 끝나면 `test/out/*.png` 를 열어 박스·흐림 위치를 확인함

## 그리기

```bash
node <스킬 폴더>/scripts/annotate.mjs \
  --in docs/screenshots/01-submit.png \
  --out docs/screenshots/01-submit-annotated.png \
  --box 130,218,105,41 \
  --blur 110,176,178,28
```

| 옵션 | 내용 |
|---|---|
| `--box x,y,width,height` | 박스를 칠 영역. 여러 번 줄 수 있음 |
| `--blur x,y,width,height` | 흐릴 영역. 여러 번 줄 수 있음 |
| `--opacity <0~1>` | 박스 바깥 어둡기 (기본 0.6). `0` 이면 어둡게 하지 않음 |
| `--padding <px>` | 박스를 영역보다 넓게 칠 픽셀 (기본 6) |

- 좌표는 이미지 픽셀임. 왼쪽 위가 `0,0`
- 지원 형식: png, jpg, webp. 결과는 항상 PNG

## 좌표 얻기

| 이미지 출처 | 방법 |
|---|---|
| `screenshot` 스킬로 찍은 웹 화면 | 찍을 때 `--locate <선택자>` 를 주면 출력 JSON 의 `located` 에 좌표가 나옴. 그대로 옮겨 씀 |
| 그 밖의 이미지 | 이미지를 열어 보고 위치를 정함. 그린 뒤 결과를 열어 어긋났으면 좌표를 고쳐 다시 그림 |

## 절차

1. **이미지 보기**: 무엇을 강조하고 무엇을 가릴지 정함
2. **좌표 정하기**: 위 "좌표 얻기"
3. **가릴 곳 확인**: API 키, 토큰, 비밀번호, 사람 이름, 전화번호가 보이면 `--blur` 에 넣음
4. **그리기**: 결과 파일 이름은 `<원본 이름>-annotated.png`
5. **눈으로 확인**: 결과를 열어 박스 위치와 가림을 확인함. 가린 글자가 읽히면 영역을 조금 넓혀 다시 그림
